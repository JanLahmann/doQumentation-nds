Quantum Approximate Optimization Algorithm

Bruukstied-Schatting: 22 Minuten op'n Heron r3 Prozessor (HENWIES: Dat is blots 'ne Schatting. Dien Looptied kann variern.)

Achtergrund​

Dit Tutorial wiest, wo wi den Quantum Approximate Optimization Algorithm (QAOA) – 'ne hybride (quanten-klassische) iterative Methode – binnen den Kontext vun Qiskit-Patterns implementeern. Wi lööst eerst dat Maximum-Cut (oder Max-Cut) Problem för 'n lütten Graphen un leert denn, wo wi dat op Utility-Skala utföhren. All Hardware-Utföhrungen in dit Tutorial schöölt binnen de Tiedgrenz för den free tögänglichen Open Plan funkeern.

Dat Max-Cut-Problem is 'n Optimierungsproblem, wat swoor to lösen is (mehr seggt, dat is 'n NP-hard Problem) mit 'ne Reeg vun verscheden Anwennungen in Clustering, Netzwerkwetenschap un statistischer Physik. Dit Tutorial betrackt 'n Graphen vun Knoten, de dör Kanten verbunnen sünd, un will de Knoten in twee Mengen optelen, sodass de Tall vun de dör dissen Schnitt dörchreisd Kanten maximiert warrt.

Vörutsettungen​

Bevör wi mit dit Tutorial anfangen, seht to, dat ji dat Folgende installeert hebbt:

  • Qiskit SDK v1.0 oder later, mit Visualisierungs-Ünnerstütten
  • Qiskit Runtime v0.22 oder later (pip install qiskit-ibm-runtime)

Daarto bruukt ji Togäng to 'ne Instanz op de IBM Quantum Platform. Acht darop, dat dit Tutorial nich in'n Open Plan utföhrt warrn kann, wieldat dat Workloads mit Sessions utföhrt, de blots mit Premium Plan-Togäng verfögbor sünd.

Deel I. QAOA in'n lütten Mootstav​

De eerste Deel vun dit Tutorial bruukt 'n lütt Max-Cut-Problem, üm de Schritten för de Lösung vun 'n Optimierungsproblem mit 'n Quantencomputer to verdüütlichen.

Üm 'n beter Kontext to geven, bevör wi dit Problem op 'n Quantenalgorithmus afbilden, köönt ji beter verstahn, wo dat Max-Cut-Problem to 'n klassischen kombinatorischen Optimierungsproblem warrt, wenn wi eerst de Minimierung vun 'ne Funkschoon f(x)f(x)f(x) betrachten

min⁡x∈{0,1}nf(x),\min_{x\in \{0, 1\}^n}f(x),x∈{0,1}nmin​f(x),

wobei de Ingav xxx 'n Vektor is, wo sien Komponenten elkeen Knoten vun 'n Graphen entsprecht. Denn warrt jede vun disse Komponenten op entweder 000 oder 111 beschränkt (wat representeert, of se in'n Schnitt entholln sünd oder nich). Dissen lüttskalige Biespielfall bruukt 'n Graphen mit n=5n=5n=5 Knoten.

Wi köönt 'ne Funkschoon vun 'n Knotenpaar i,ji,ji,j schrieven, wat anwiest, of de entsprechend Kant (i,j)(i,j)(i,j) in'n Schnitt liggt. To'n Biespeel is de Funkschoon xi+xj−2xixjx_i + x_j - 2 x_i x_jxi​+xj​−2xi​xj​ nau denn 1, wenn entweder xix_ixi​ oder xjx_jxj​ gliek 1 is (wat bedüüdt, dat de Kant in'n Schnitt liggt) un süss null. Dat Problem, de Kanten in'n Schnitt to maximeren, kann formuleert warrn as

max⁡x∈{0,1}n∑(i,j)xi+xj−2xixj,\max_{x\in \{0, 1\}^n} \sum_{(i,j)} x_i + x_j - 2 x_i x_j,x∈{0,1}nmax​(i,j)∑​xi​+xj​−2xi​xj​,

wat as Minimierung ümschreven warrn kann in de Form

min⁡x∈{0,1}n∑(i,j)2xixj−xi−xj.\min_{x\in \{0, 1\}^n} \sum_{(i,j)} 2 x_i x_j - x_i - x_j.x∈{0,1}nmin​(i,j)∑​2xi​xj​−xi​−xj​.

Dat Minimum vun f(x)f(x)f(x) in dissen Fall liggt vör, wenn de Tall vun de dör den Schnitt dörchreisd Kanten maximal is. As ji seht, hett dat noch nix mit Quantencomputing to doon. Wi mööt dit Problem in wat ümformuleren, wat 'n Quantencomputer verstahn kann. Initiali seert juu Problem, indem wi 'n Graphen mit n=5n=5n=5 Knoten maakt.

Schritt 1: Klassische Ingav op 'n Quantenproblem afbilden​

De eerste Schritt vun't Pattern besteiht darin, dat klassische Problem (Graph) op quantenmechanische Schaltkreise un Operatoren aftobilden. Daarto sünd dree Hövdschritten to ünnernahmen:

  1. Bruuk vun 'ne Reeg vun mathematische Ümformulierungen, üm dit Problem mit de Notation vun Quadratic Unconstrained Binary Optimization (QUBO) Problemen dartostellen.
  2. Ümformulierung vun't Optimierungsproblem as Hamilton-Operator, för den de Grundtostänn de Lösung entspricht, wo de Kostenfunkschoon minimieeert.
  3. Maaken vun 'n Quantenschaltkreis, de den Grundtostänn vun dissen Hamilton-Operator över 'n Prozess ähnlich dat Quantum Annealing vörbereit.

Acht darop: In de QAOA-Methodik wüllt wi letztlich 'n Operator (Hamilton-Operator) hemm, de de Kostenfunkschoon vun uns hybride Algorithmus darstellt, sowiet as 'n parametriseerten Schaltkreis (Ansatz), de Quantentostänne mit Kandidatenlösungen för dit Problem darstellt. Wi köönt ut disse Kandidatentostänne sampeln un se denn mit de Kostenfunkschoon bewerten.

Graph → Optimierungsproblem​

De eerste Schritt vun de Afbildung is 'ne Notationsännerung. Dat Folgende drückt dit Problem in QUBO-Notation ut:

min⁡x∈{0,1}nxTQx,\min_{x\in \{0, 1\}^n}x^T Q x,x∈{0,1}nmin​xTQx,

wobei QQQ 'ne n×nn\times nn×n Matrix vun reelle Tallen is, nnn de Tall vun de Knoten in juu Graphen entspricht, xxx de boven inföhrde Vektor vun binäre Variable is un xTx^TxT de Transponeerde vun den Vektor xxx bedüüdt.

 + 2*x_1 + 3*x_2 + 2*x_3 + 2*x_4

Optimierungsproblem → Hamilton-Operator​

Wi köönt denn dat QUBO-Problem as Hamilton-Operator ümformuleren (hier 'ne Matrix, wo de Energie vun 'n System darstellt):

HC=∑ijQijZiZj+∑ibiZi.H_C=\sum_{ij}Q_{ij}Z_iZ_j + \sum_i b_iZ_i.HC​=ij∑​Qij​Zi​Zj​+i∑​bi​Zi​.

Ümformulierungsschritten vun't QAOA-Problem to'n Hamilton-Operator

Üm to wiesen, wo dat QAOA-Problem op disse Wies ümschreven warrn kann, ersettt wi eerst de binären Variable xix_ixi​ dör 'n nijen Sett vun Variable zi∈{−1,1}z_i\in\{-1, 1\}zi​∈{−1,1} över

xi=1−zi2.x_i = \frac{1-z_i}{2}.xi​=21−zi​​.

Hier köönt ji sehn, dat wenn xix_ixi​ gliek 000 is, denn ziz_izi​ gliek 111 sien mutt. Wenn de xix_ixi​ dör de ziz_izi​ in't Optimierungsproblem (xTQxx^TQxxTQx) ersett warrt, kann 'ne äquivalente Formulierung kregen warrn.

xTQx=∑ijQijxixj=14∑ijQij(1−zi)(1−zj)=14∑ijQijzizj−14∑ij(Qij+Qji)zi+n24.x^TQx=\sum_{ij}Q_{ij}x_ix_j \\ =\frac{1}{4}\sum_{ij}Q_{ij}(1-z_i)(1-z_j) \\=\frac{1}{4}\sum_{ij}Q_{ij}z_iz_j-\frac{1}{4}\sum_{ij}(Q_{ij}+Q_{ji})z_i + \frac{n^2}{4}.xTQx=ij∑​Qij​xi​xj​=41​ij∑​Qij​(1−zi​)(1−zj​)=41​ij∑​Qij​zi​zj​−41​ij∑​(Qij​+Qji​)zi​+4n2​.

Wenn wi nu bi=−∑j(Qij+Qji)b_i=-\sum_{j}(Q_{ij}+Q_{ji})bi​=−∑j​(Qij​+Qji​) definiern, den Vörfaktor wegnehmen un den konstanten Term n2n^2n2 weglaten, kriegen wi de beiden äquivalenten Formulierungen vun't sülve Optimierungsproblem.

min⁡x∈{0,1}nxTQx⟺min⁡z∈{−1,1}nzTQz+bTz\min_{x\in\{0,1\}^n} x^TQx\Longleftrightarrow \min_{z\in\{-1,1\}^n}z^TQz + b^Tzx∈{0,1}nmin​xTQx⟺z∈{−1,1}nmin​zTQz+bTz

Hier hängt bbb vun QQQ af. Acht darop, dat wi för de Erlangung vun zTQz+bTzz^TQz + b^TzzTQz+bTz den Faktor 1/4 un 'n konstanten Offset vun n2n^2n2 weggelaten hebbt, de bi de Optimierung keen Roll speelt.

Üm nu 'ne Quantenformulierung vun't Problem to kriegen, erheven wi de Variable ziz_izi​ to 'ne Pauli ZZZ Matrix, liek as 'ne 2×22\times 22×2 Matrix vun de Form

Zi=(100−1).Z_i = \begin{pmatrix}1 & 0 \\ 0 & -1\end{pmatrix}.Zi​=(10​0−1​).

Wenn wi disse Matrizen in't boven Optimierungsproblem insetten, kriegen wi den folgenden Hamilton-Operator

HC=∑ijQijZiZj+∑ibiZi.H_C=\sum_{ij}Q_{ij}Z_iZ_j + \sum_i b_iZ_i.HC​=ij∑​Qij​Zi​Zj​+i∑​bi​Zi​.

Acht ok darop, dat de ZZZ Matrizen in den Rekenruum vun den Quantencomputer inbedd sünd, dat heet in 'n Hilbert-Ruum vun de Gröte 2n×2n2^n\times 2^n2n×2n. Dorüm schöölt wi Termen as ZiZjZ_iZ_jZi​Zj​ as dat Tensorprodukt Zi⊗ZjZ_i\otimes Z_jZi​⊗Zj​ verstahn, wat in den 2n×2n2^n\times 2^n2n×2n Hilbert-Ruum inbedd is. To'n Biespeel warrt in 'n Problem mit fief Entscheidungsvariabeln de Term Z1Z3Z_1Z_3Z1​Z3​ as I⊗Z3⊗I⊗Z1⊗II\otimes Z_3\otimes I\otimes Z_1\otimes II⊗Z3​⊗I⊗Z1​⊗I verstahn, wobei III de 2×22\times 22×2 Eenheitsmatrix is.

Dissen Hamilton-Operator warrt as Kostenfunkschoons-Hamilton-Operator beseekent. He hett de Egenschop, dat sien Grundtostänn de Lösung entspricht, wo de Kostenfunkschoon f(x)f(x)f(x) minimieeert. Üm juu Optimierungsproblem to lösen, mööt wi nu den Grundtostänn vun HCH_CHC​ (oder 'n Tostänn mit hoge Överlappung dormit) op'n Quantencomputer präpareren. Dat Sampeln ut dissen Tostänn warrt denn mit hoge Wahrschienlichkeit de Lösung to min f(x)min~f(x)min f(x) levern. Betrach wi nu den Hamilton-Operator HCH_CHC​ för dat Max-Cut Problem. Elkeen Knoten vun den Graphen warrt 'n Qubit in'n Tostänn ∣0⟩|0\rangle∣0⟩ oder ∣1⟩|1\rangle∣1⟩ toordnet, wobei de Wert de Meng anwiest, to de de Knoten hört. Dat Ziel vun't Problem is dat, de Tall vun de Kanten (v1,v2)(v_1, v_2)(v1​,v2​) to maximeren, för wo v1=∣0⟩v_1 = |0\ranglev1​=∣0⟩ un v2=∣1⟩v_2 = |1\ranglev2​=∣1⟩ gellt, oder ümkehrt. Wenn wi den ZZZ Operator elkeen Qubit toordnen, wobei

Z∣0⟩=∣0⟩Z∣1⟩=−∣1⟩ Z|0\rangle = |0\rangle \qquad Z|1\rangle = -|1\rangleZ∣0⟩=∣0⟩Z∣1⟩=−∣1⟩

denn hört 'ne Kant (v1,v2)(v_1, v_2)(v1​,v2​) to'n Schnitt, wenn de Eigenwert vun (Z1∣v1⟩)⋅(Z2∣v2⟩)=−1(Z_1|v_1\rangle) \cdot (Z_2|v_2\rangle) = -1(Z1​∣v1​⟩)⋅(Z2​∣v2​⟩)=−1 is; mit anner Wöör, de mit v1v_1v1​ un v2v_2v2​ assozieerten Qubits sünd verscheden. Ebenso hört (v1,v2)(v_1, v_2)(v1​,v2​) nich to'n Schnitt, wenn de Eigenwert vun (Z1∣v1⟩)⋅(Z2∣v2⟩)=1(Z_1|v_1\rangle) \cdot (Z_2|v_2\rangle) = 1(Z1​∣v1​⟩)⋅(Z2​∣v2​⟩)=1 is. Acht darop, dat uns de genau Qubit-Tostänn, de elkeen Knoten toordnet is, nich interesseert, süss blots, of se över 'ne Kant henweg gliek sünd oder nich. Dat Max-Cut-Problem verlang vun uns, 'ne Toordnung vun de Qubits op de Knoten to finnen, sodass de Eigenwert vun den folgenden Hamilton-Operator minimiiert warrt

HC=∑(i,j)∈eQij⋅ZiZj. H_C = \sum_{(i,j) \in e} Q_{ij} \cdot Z_i Z_j.HC​=(i,j)∈e∑​Qij​⋅Zi​Zj​.

Mit anner Wöör, bi=0b_i = 0bi​=0 för all iii in't Max-Cut-Problem. De Wert vun QijQ_{ij}Qij​ bedüüdt dat Gewicht vun de Kant. In dit Tutorial betrachten wi 'n ungewichteten Graphen, dat heet Qij=1.0Q_{ij} = 1.0Qij​=1.0 för all i,ji, ji,j.

def build_max_cut_paulis(
    graph: rx.PyGraph,
) -> list[tuple[str, list[int], float]]:
    """Convert the graph to Pauli list.

    This function does the inverse of `build_max_cut_graph`
    """
    pauli_list = []
    for edge in list(graph.edge_list()):
        weight = graph.get_edge_data(edge[0], edge[1])
        pauli_list.append(("ZZ", [edge[0], edge[1]], weight))
    return pauli_list

Hamilton-Operator → Quantenschaltkreis​

De Hamilton-Operator HCH_CHC​ enthält de Quantendefinischoon vun juu Problem. Nu köönt wi 'n Quantenschaltkreis maken, de dorbi hülpt, gode Lösungen vun den Quantencomputer to sampeln. De QAOA is inspireert vun't Quantum Annealing un wendt afwesselnde Schichten vun Operatoren in'n Quantenschaltkreis an.

De allgemene Idee besteiht darin, in'n Grundtostänn vun 'n bekannten System to beginnen, H⊗n∣0⟩H^{\otimes n}|0\rangleH⊗n∣0⟩ boven, un denn dat System in den Grundtostänn vun den Kostenoperator to stüern, an den wi interessiert sünd. Dat schütt dör Anwendung vun de Operatoren exp⁡{−iγkHC}\exp\{-i\gamma_k H_C\}exp{−iγk​HC​} un exp⁡{−iβkHm}\exp\{-i\beta_k H_m\}exp{−iβk​Hm​} mit Winkeln γ1,...,γp\gamma_1,...,\gamma_pγ1​,...,γp​ un β1,...,βp \beta_1,...,\beta_p~β1​,...,βp​ .

De vun uns genereert Quantenschaltkreis is parametriseert dör γi\gamma_iγi​ un βi\beta_iβi​, sodass wi verscheden Werte vun γi\gamma_iγi​ un βi\beta_iβi​ utproberen un ut den resultierenden Tostänn sampeln köönt.

Schritt 3: Utföhrung mit Qiskit Primitives​

In'n QAOA-Workflow warrt de optimalen QAOA-Parameter in 'ne iterative Optimierungsslöp funnen, wo 'ne Reeg vun Schaltkreisbewertungen utföhrt un 'n klassischen Optimierer bruukt, üm de optimalen βk\beta_kβk​ un γk\gamma_kγk​ Parameter to finnen. Disse Utföhrungsslöp warrt över de folgenden Schritten utföhrt:

  1. Defineren vun de initialen Parameter
  2. Instanziierung vun 'ne nije Session, wo de Optimierungsslöp un dat Primitive enthölt, wat to'n Sampeln vun den Schaltkreis bruukt warrt
  3. Sobald 'n optimalen Parametersett funnen is, föhrt wi den Schaltkreis 'n letzt Mal ut, üm 'ne finale Verdelung to kriegen, wo in'n Post-Processing-Schritt bruukt warrt.

_PARITY = np.array(
    [-1 if bin(i).count("1") % 2 else 1 for i in range(256)],
    dtype=np.complex128,
)

def evaluate_sparse_pauli(state: int, observable: SparsePauliOp) -> complex:
    """Utility for the evaluation of the expectation value of a measured state."""
    packed_uint8 = np.packbits(observable.paulis.z, axis=1, bitorder="little")
    state_bytes = np.frombuffer(
        state.to_bytes(packed_uint8.shape[1], "little"), dtype=np.uint8
    )
    reduced = np.bitwise_xor.reduce(packed_uint8 & state_bytes, axis=1)
    return np.sum(observable.coeffs * _PARITY[reduced])

def best_solution(samples, hamiltonian):
    """Find solution with lowest cost"""
    min_cost = 1000
    min_sol = None
    for bit_str in samples.keys():
        # Qiskit use little endian hence the [::-1]
        candidate_sol = int(bit_str)
        # fval = qp.objective.evaluate(candidate_sol)
        fval = evaluate_sparse_pauli(candidate_sol, hamiltonian).real
        if fval <= min_cost:
            min_sol = candidate_sol

    return min_sol

# auxiliary function to help plot cumulative distribution functions
def _plot_cdf(objective_values: dict, ax, color):
    x_vals = sorted(objective_values.keys(), reverse=True)
    y_vals = np.cumsum([objective_values[x] for x in x_vals])
    ax.plot(x_vals, y_vals, color=color)

def plot_cdf(dist, ax, title):
    _plot_cdf(
        dist,
        ax,
        "C1",
    )
    ax.vlines(min(list(dist.keys())), 0, 1, "C1", linestyle="--")

    ax.set_title(title)
    ax.set_xlabel("Objective function value")
    ax.set_ylabel("Cumulative distribution function")
    ax.grid(alpha=0.3)

# auxiliary function to convert bit-strings to objective values
def samples_to_objective_values(samples, hamiltonian):
    """Convert the samples to values of the objective function."""

    objective_values = defaultdict(float)
    for bit_str, prob in samples.items():
        candidate_sol = int(bit_str)
        fval = evaluate_sparse_pauli(candidate_sol, hamiltonian).real
        objective_values[fval] += prob

    return objective_values
